DELIMITER //
CREATE PROCEDURE GetCustomerSales(IN CustID INT, OUT TotalSales INT)
BEGIN
    SELECT COUNT(SaleID) INTO TotalSales
    FROM Sales
    WHERE CustomerID = CustID;
END //

13. Create one trigger (BEFORE UPDATE)


DELIMITER //
CREATE TRIGGER BeforeMedicineUpdate
BEFORE UPDATE ON Medicines
FOR EACH ROW
BEGIN
    IF NEW.Cost < 0 THEN
        SET NEW.Cost = 0; -- Prevent negative cost
    END IF;
END //
DELIMITER ;







MongoDB
-----------
Create Database in MongoDB for Medical Store(Like Wellness Forever) System. - 5 Marks


1. Write the command for creating collection & for inserting documents in collections(1)
2. Write  a command to list all from the result (1)
3. Use the $or operator to find medicines based on multiple conditions (for example: price greater than 200 or category is 'Pain Relief')(1)
4. Write a command to sort the result in descending order based on Medicine cost(1)
5. Create an index on the name (of medicine) field. (1)


1. Create collection & insert documents


// Create collection
db.createCollection("Medicines");


// Insert documents
db.Medicines.insertMany([
  { MedicineID: 1, Name: "Paracetamol", Price: 50, Category: "Pain Relief" },
  { MedicineID: 2, Name: "Amoxicillin", Price: 250, Category: "Antibiotic" },
  { MedicineID: 3, Name: "Vitamin C", Price: 150, Category: "Supplement" }
]);
2. List all from the result


db.Medicines.find({});
3. Use $or operator (multiple conditions)


db.Medicines.find({
  $or: [
    { Price: { $gt: 200 } },
    { Category: "Pain Relief" }
  ]
});
4. Sort result in descending order based on Medicine cost


db.Medicines.find().sort({ Price: -1 });
5. Create an index on medicine name field


db.Medicines.createIndex({ Name: 1 });
