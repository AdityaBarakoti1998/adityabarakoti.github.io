10. Write a command to use LEFT JOIN (3) 


SELECT
Orders.OrderID,
Customer.CustomerName,
Product.ProductName,
Orders.Quantity
FROM Orders
LEFT JOIN Customer
ON Orders.CustomerID=Customer.CustomerID
LEFT JOIN Product
ON Orders.ProductID=Product.ProductID;

12. Create at least one procedure (with one INPUT and one OUTPUT parameter) based on the created tables with appropriate utility (3) 


DELIMITER $$


CREATE PROCEDURE GetProductCount(
IN p_category VARCHAR(30),
OUT total INT
)


BEGIN


SELECT COUNT(*)
INTO total
FROM Product
WHERE Category=p_category;


END $$


DELIMITER ;


Run Procedure: 
CALL GetProductCount('Grocery',@count);


SELECT @count;


13. Create a ONE trigger of BEFORE UPDATE ON any one of the table(3)


 DELIMITER $$


CREATE TRIGGER trg_before_update
BEFORE UPDATE
ON Product
FOR EACH ROW


BEGIN
IF NEW.Price<0 THEN
SET NEW.Price=OLD.Price;
END IF;
END $$


DELIMITER ;

Create Database in MongoDB for Supermarket Store(Like DMart) System. - 5 Marks 
1. Write the command for creating collection & for inserting documents in collections(1) 
2. Write  a command to list all from the result (1) 
3. Use the $and operator to find products based on multiple conditions (for example: cost greater 
than 100 AND category is 'Grocery') (1) 
4. Write a command to sort the result in descending order based on Product cost(1) 
5. Create an index on the name (of product) field. (1) 




1. Create collection & insert documents 


javascript 
// Create collection 
db.createCollection("Products"); 
// Insert documents 
db.Products.insertMany([ 
{ ProductID: 1, Name: "Rice", Cost: 120, Category: "Grocery" }, 
{ ProductID: 2, Name: "Milk", Cost: 40, Category: "Dairy" }, 
{ ProductID: 3, Name: "Soap", Cost: 25, Category: "Personal Care" } 
]); 




2. List all from the result 


javascript 
db.Products.find({}); 


3. Use $and operator (multiple conditions) 


javascript 
db.Products.find({ 
$and: [ 
{ Cost: { $gt: 100 } }, 
{ Category: "Grocery" } 
] 
}); 


4. Sort result in descending order based on Product cost 


javascript 
db.Products.find().sort({ Cost: -1 }); 


5. Create an index on product name field 


javascript 
db.Products.createIndex({ Name: 1 });
